## How to Update This Registry

1. Run a new inventory session (read-only). Reference `AI_Studio/Reports/system_inventory_2026-05-26/` as the prior-session baseline.
2. Add new rows for any new system. Do NOT remove rows for deprecated systems — mark them BROKEN or DORMANT and add a dated note.
3. Update Status column and Evidence column together. A status change with no evidence update is a policy violation.
4. Never include personal corpus paths (`Excluded`, `IMPORTANT DOCS`, `Case_Reference`, `Desktop\Excluded`, SSN, credentials). Repo-relative paths only.
5. After editing, update the "Last updated" date at the top of this file.
