# Handoff Index Rebuild

The `INDEX.md` in `~/VoxCore/handoffs/` is the data layer for cross-cutting queries ("which subsystems got handoffs this quarter", "which projects have gone > 30 days without a handoff", "what recurring topics show up in insights"). It's incrementally updated by `/handoff`, but drift happens — files get renamed, manually moved, or corrupted. This skill rebuilds it from scratch.

## Arguments

`$ARGUMENTS` — optional: filter by project key (`calmcore`, `voxcore`, `calmsniffer`) to rebuild only that project's rows. Default: full rebuild.

## Process

### Step 1: Discover handoffs

Scan each known project's `AI_Studio/Handoffs/` directory:

```
C:/Users/atayl/CalmCore/AI_Studio/Handoffs/*.md
C:/Users/atayl/VoxCore/AI_Studio/Handoffs/*.md
C:/Users/atayl/CalmSniffer/AI_Studio/Handoffs/*.md
```

Use `Glob` for each. Exclude any filename starting with `_` (e.g., `_latest.md` symlink, `_insights/`, etc.).

If `$ARGUMENTS` is provided, only scan that project's directory.

### Step 2: Extract metadata per handoff

For each discovered file:

1. **Date** — parse from filename prefix `YYYY-MM-DD_*`. If the filename doesn't match the convention, fall back to file mtime (`stat -c '%y'`).
2. **Project** — derive from the path (the directory under `/c/Users/atayl/`).
3. **Topic (label)** — the filename stem after the date prefix, minus `.md`.
4. **Branch + last commit** — read from the handoff's markdown header (the `**Branch**:` and `**Last commit**:` lines written by `/handoff`). If missing, leave blank.
5. **Size** — file size in KB for sanity (handoffs should be 2-15 KB; much larger or smaller flags a problem).

Non-conforming filenames (no date prefix) should be surfaced in a "Hygiene Warnings" section at the bottom of INDEX.md — don't silently skip them.

### Step 3: Build the index

Write `~/VoxCore/handoffs/INDEX.md` with this structure:

```markdown
# Handoff Index
_Auto-generated by `/handoff-index`. Last rebuild: <ISO timestamp>._

## Active Handoffs (by date, newest first)

| Date | Project | Topic | Branch | Last Commit | Size | Path |
|------|---------|-------|--------|-------------|------|------|
| 2026-04-12 | calmcore | ai-audit-pass2 | master | 4317d6e041 | 8.1 KB | [open](../../CalmCore/AI_Studio/Handoffs/2026-04-12_ai-audit-pass2.md) |
| 2026-04-12 | calmsniffer | aes-gcm-decrypt | master | 258b79c | 6.0 KB | [open](../../CalmSniffer/AI_Studio/Handoffs/2026-04-12_aes-gcm-decrypt.md) |
| ... | | | | | | |

## Project Activity Summary

| Project | Handoff Count | Oldest | Newest | Days Since Last |
|---------|---------------|--------|--------|-----------------|
| calmcore | N | 2026-04-01 | 2026-04-12 | 0 |
| calmsniffer | N | ... | ... | ... |
| voxcore | N | ... | ... | ... |

## Hygiene Warnings

- [files with non-conforming names, stale handoffs > 30 days, etc.]
- [broken hardlinks — canonical file exists but Desktop shelf link is missing]
- [Desktop shelf links pointing to files that no longer exist in canonical location]

## Insights / Gap Analysis / Hygiene Files

Links to anything in `_insights/`, `_gap-analysis/`, `_hygiene/`.

- [_insights/<file>.md](_insights/<file>.md)
- ...
```

### Step 4: Sanity checks

Before writing, verify:

1. **Hardlink integrity** — for every handoff in a project's `AI_Studio/Handoffs/`, check that a corresponding file exists in `~/Desktop/AI_Handoffs/<project>/` with the same inode (via `stat -c '%i'`). Mismatches go in Hygiene Warnings.

2. **Filename convention** — every filename must match `^\d{4}-\d{2}-\d{2}_.+\.md$`. Non-conforming files go in Hygiene Warnings.

3. **Stale handoffs** — any handoff > 30 days old without a follow-up handoff in the same project is flagged.

### Step 5: Output summary

Show the user:
- Total handoffs indexed per project
- Number of hygiene warnings (with top 3 specifics)
- Path to the regenerated INDEX.md
- Suggested next action (`/handoff` if one project has > 30 days since last)

## Rules

- **Never delete handoffs** — hygiene warnings are informational. The user decides whether to prune.
- **Idempotent** — running the skill twice in a row should produce identical output (modulo the "last rebuild" timestamp).
- **Preserve `_insights/`, `_gap-analysis/`, `_hygiene/` content** — the skill builds the INDEX.md but does not touch those folders.
- **Relative paths in links** — INDEX.md sits in `VoxCore/handoffs/`; paths to handoffs are `../../<Project>/AI_Studio/Handoffs/<file>.md`. Keeps the index portable.
